     1→     1→# Letta (MemGPT) Self-Directed Memory Management Research
     2→     2→
     3→     3→## Executive Summary
     4→     4→
     5→     5→Letta (formerly MemGPT) is a revolutionary platform for building stateful AI agents with self-directed memory management. It implements an OS-inspired hierarchical memory architecture that enables agents to overcome LLM context window limitations through autonomous memory decisions.
     6→     6→
     7→     7→**Key Innovation**: Agents can self-edit their own memory using function tools, deciding what to remember, forget, and consolidate without human intervention.
     8→     8→
     9→     9→---
    10→    10→
    11→    11→## 1. Letta Architecture: Self-Directed Memory Implementation
    12→    12→
    13→    13→### 1.1 Core Concept: LLM as Operating System
    14→    14→
    15→    15→Letta implements the "LLM as Operating System" paradigm from the MemGPT paper (arXiv:2310.08560):
    16→    16→
    17→    17→```
    18→    18→┌─────────────────────────────────────────────────────────────┐
    19→    19→│                    LETTA AGENT ARCHITECTURE                  │
    20→    20→├─────────────────────────────────────────────────────────────┤
    21→    21→│                                                              │
    22→    22→│  ┌─────────────────────────────────────────────────────┐    │
    23→    23→│  │              MAIN CONTEXT (Limited)                  │    │
    24→    24→│  │  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐    │    │
    25→    25→│  │  │   SYSTEM    │ │   CORE      │ │  WORKING    │    │    │
    26→    26→│  │  │   PROMPT    │ │   MEMORY    │ │  MEMORY     │    │    │
    27→    27→│  │  │  (Persona)  │ │  (Blocks)   │ │ (Messages)  │    │    │
    28→    28→│  │  └─────────────┘ └─────────────┘ └─────────────┘    │    │
    29→    29→│  │         ↑ Always in context (like RAM)              │    │
    30→    30→│  └─────────────────────────────────────────────────────┘    │
    31→    31→│                         ↕                                    │
    32→    32→│  ┌─────────────────────────────────────────────────────┐    │
    33→    33→│  │           EXTERNAL MEMORY (Unlimited)                │    │
    34→    34→│  │  ┌─────────────────┐ ┌─────────────────────────┐    │    │
    35→    35→│  │  │     RECALL      │ │      ARCHIVAL           │    │    │
    36→    36→│  │  │     MEMORY      │ │      MEMORY             │    │    │
    37→    37→│  │  │ (Message DB)    │ │ (Vector Database)       │    │    │
    38→    38→│  │  └─────────────────┘ └─────────────────────────┘    │    │
    39→    39→│  │         ↑ Requires retrieval (like Disk)            │    │
    40→    40→│  └─────────────────────────────────────────────────────┘    │
    41→    41→│                                                              │
    42→    42→└─────────────────────────────────────────────────────────────┘
    43→    43→```
    44→    44→
    45→    45→### 1.2 Memory Hierarchy (OS-Inspired)
    46→    46→
    47→    47→| Memory Tier | Analogy | Characteristics | Capacity |
    48→    48→|-------------|---------|-----------------|----------|
    49→    49→| **Main Context** | CPU Registers | Always visible to LLM | Fixed (context window) |
    50→    50→| **Core Memory** | RAM | In-context, self-editable | Limited (~2000-8000 tokens) |
    51→    51→| **Recall Memory** | Page Cache | Conversation history | Semi-limited |
    52→    52→| **Archival Memory** | Disk/SSD | Vector DB, searchable | Unlimited |
    53→    53→

    98→    98→## 2. Memory Tiers: Detailed Breakdown
    99→    99→
   100→   100→### 2.1 Core Memory (Memory Blocks)
   101→   101→
   102→   102→**Definition**: Structured sections of the agent's context window that persist across all interactions. Always visible - no retrieval needed.
   103→   103→
   104→   104→```python
   105→   105→# Core Memory Structure
   106→   106→class CoreMemoryBlock:
   107→   107→    """A structured memory block in core memory"""
   108→   108→    label: str           # e.g., "persona", "human", "tasks"
   109→   109→    content: str         # The actual content
   110→   110→    limit: int           # Character/token limit
   111→   111→    priority: int        # Importance for context management
   112→   112→
   113→   113→# Default Core Memory Blocks
   114→   114→DEFAULT_BLOCKS = {
   115→   115→    "persona": {
   116→   116→        "description": "AI's identity and capabilities",
   117→   117→        "limit": 2000,
   118→   118→        "content": "I am a helpful AI assistant..."
   119→   119→    },
   120→   120→    "human": {
   121→   121→        "description": "User information and preferences",
   122→   122→        "limit": 2000,
   123→   123→        "content": "User prefers Python..."
   124→   124→    }
   125→   125→}
   126→   126→```
   127→   127→
   128→   128→**Key Characteristics**:
   129→   129→- **Always in context**: No retrieval overhead
   130→   130→- **Self-editable**: Agent can modify using tools
   131→   131→- **Structured**: Organized by topic/purpose
   132→   132→- **Limited**: Must be carefully managed
   133→   133→
   134→   134→### 2.2 Working Memory (Message Queue)
   135→   135→
   136→   136→**Definition**: Recent conversation messages in the main context. Analogous to CPU cache.
   137→   137→
   138→   138→```python
   139→   139→# Working Memory Management
   140→   140→class WorkingMemory:
   141→   141→    """Recent messages in main context"""
   142→   142→    
   143→   143→    def __init__(self, max_messages: int = 10):
   144→   144→        self.messages = []
   145→   145→        self.max_messages = max_messages
   146→   146→    
   147→   147→    def add_message(self, message: Message):
   148→   148→        """Add message, evict oldest if needed"""
   149→   149→        self.messages.append(message)
   150→   150→        if len(self.messages) > self.max_messages:
   151→   151→            # Oldest messages moved to recall memory
   152→   152→            self._evict_oldest()
   153→   153→    
   154→   154→    def get_context(self) -> str:
   155→   155→        """Format for LLM context"""
   156→   156→        return "\n".join(m.content for m in self.messages)
   157→   157→```

   360→   360→## 4. Self-Modification: How Agents Modify Their Own Memory
   361→   361→
   362→   362→### 4.1 The Self-Editing Loop
   363→   363→
   364→   364→```
   365→   365→┌─────────────────────────────────────────────────────────────┐
   366→   366→│              SELF-DIRECTED MEMORY MODIFICATION               │
   367→   367→├─────────────────────────────────────────────────────────────┤
   368→   368→│                                                              │
   369→   369→│  User Message                                                │
   370→   370→│       ↓                                                      │
   371→   371→│  ┌─────────────┐                                            │
   372→   372→│  │  LLM sees   │  → Context = System + Core Memory +        │
   373→   373→│  │  context    │    Working Memory + Message                │
   374→   374→│  └─────────────┘                                            │
   375→   375→│       ↓                                                      │
   376→   376→│  ┌─────────────────────────────────────────────────┐        │
   377→   377→│  │  LLM decides:                                     │        │
   378→   378→│  │                                                   │        │
   379→   379→│  │  1. Do I need to REMEMBER this?                  │        │
   380→   380→│  │     → core_memory_append()                       │        │
   381→   381→│  │                                                   │        │
   382→   382→│  │  2. Is this important for long-term?             │        │
   383→   383→│  │     → archival_memory_insert()                   │        │
   384→   384→│  │                                                   │        │
   385→   385→│  │  3. Do I need to UPDATE existing memory?         │        │
   386→   386→│  │     → core_memory_replace()                      │        │
   387→   387→│  │                                                   │        │
   388→   388→│  │  4. Do I need to RECALL past info?               │        │
   389→   389→│  │     → archival_memory_search()                   │        │
   390→   390→│  │     → conversation_search()                      │        │
   391→   391→│  │                                                   │        │
   392→   392→│  │  5. Is this outdated/WRONG?                      │        │
   393→   393→│  │     → archival_memory_delete()                   │        │
   394→   394→│  │                                                   │        │
   395→   395→│  └─────────────────────────────────────────────────┘        │
   396→   396→│       ↓                                                      │
   397→   397→│  Tool Execution → Memory State Updated                       │
   398→   398→│       ↓                                                      │
   399→   399→│  Response Generation                                         │
   400→   400→│                                                              │
   401→   401→└─────────────────────────────────────────────────────────────┘
   402→   402→```

   483→   483→## 5. Key Algorithms: Memory Management
   484→   484→
   485→   485→### 5.1 Context Window Management (Heartbeats)
   486→   486→
   487→   487→Letta uses a "heartbeat" mechanism for context management:
   488→   488→
   489→   489→```python
   490→   490→# Heartbeat-based context management
   491→   491→class HeartbeatManager:
   492→   492→    """
   493→   493→    Periodically triggers context evaluation and management.
   494→   494→    Similar to OS memory management interrupts.
   495→   495→    """
   496→   496→    
   497→   497→    def __init__(self, max_context_tokens: int = 8000):
   498→   498→        self.max_tokens = max_context_tokens
   499→   499→        self.heartbeat_interval = 10  # messages
   500→   500→    
   501→   501→    async def check_and_compact(self, state: AgentState):
   502→   502→        """Check if context compaction is needed"""
   503→   503→        current_tokens = self._count_tokens(state)
   504→   504→        
   505→   505→        if current_tokens > self.max_tokens * 0.8:
   506→   506→            # Trigger compaction
   507→   507→            await self._compact_context(state)
   508→   508→    
   509→   509→    async def _compact_context(self, state: AgentState):
   510→   510→        """Compact context by summarizing old messages"""
   511→   511→        # 1. Summarize old messages
   512→   512→        summary = await self._summarize_messages(
   513→   513→            state.messages[:-5]  # Keep recent 5
   514→   514→        )
   515→   515→        
   516→   516→        # 2. Store summary in archival memory
   517→   517→        await state.archival_memory.insert(
   518→   518→            f"Conversation summary: {summary}"
   519→   519→        )
   520→   520→        
   521→   521→        # 3. Remove compacted messages from working memory
   522→   522→        state.messages = state.messages[-5:]
   523→   523→        
   524→   524→        # 4. Update core memory if needed
   525→   525→        # Agent decides via tool calls
   526→   526→```
   527→   527→
   528→   528→### 5.2 Memory Consolidation
   529→   529→
   530→   530→```python
   531→   531→# Memory consolidation algorithm (conceptual)
   532→   532→class MemoryConsolidation:
   533→   533→    """
   534→   534→    Consolidate information across memory tiers.
   535→   535→    Inspired by sleep-dependent memory consolidation.
   536→   536→    """
   537→   537→    
   538→   538→    async def consolidate_session(self, session_id: str):
   539→   539→        """Consolidate session memories into long-term storage"""
   540→   540→        
   541→   541→        # 1. Extract key facts from session
   542→   542→        session_memories = await self.recall_memory.get_session(session_id)
   543→   543→        key_facts = await self._extract_facts(session_memories)
   544→   544→        
   545→   545→        # 2. Check for conflicts with existing memories
   546→   546→        for fact in key_facts:
   547→   547→            conflicts = await self._find_conflicts(fact)
   548→   548→            
   549→   549→            if conflicts:
   550→   550→                # Resolve conflicts - keep most recent/relevant
   551→   551→                await self._resolve_conflict(fact, conflicts)
   552→   552→            else:
   553→   553→                # Store new fact
   554→   554→                await self.archival_memory.insert(fact)
   555→   555→        
   556→   556→        # 3. Update core memory if user preferences changed
   557→   557→        await self._update_core_memory_preferences()
   558→   558→```

   560→   560→### 5.3 Relevance Scoring
   561→   561→
   562→   562→```python
   563→   563→# Relevance scoring for memory retrieval
   564→   564→class RelevanceScorer:
   565→   565→    """
   566→   566→    Score memory relevance for retrieval decisions.
   567→   567→    """
   568→   568→    
   569→   569→    def compute_relevance(
   570→   570→        self,
   571→   571→        query: str,
   572→   572→        memory: MemoryItem,
   573→   573→        context: Dict
   574→   574→    ) -> float:
   575→   575→        """
   576→   576→        Compute relevance score combining multiple factors.
   577→   577→        
   578→   578→        Returns:
   579→   579→            Score between 0 and 1
   580→   580→        """
   581→   581→        scores = {}
   582→   582→        
   583→   583→        # 1. Semantic similarity (vector embedding)
   584→   584→        scores['semantic'] = self._semantic_similarity(
   585→   585→            query, memory.content
   586→   586→        )
   587→   587→        
   588→   588→        # 2. Recency factor
   589→   589→        scores['recency'] = self._recency_score(
   590→   590→            memory.timestamp
   591→   591→        )
   592→   592→        
   593→   593→        # 3. Access frequency
   594→   594→        scores['frequency'] = self._frequency_score(
   595→   595→            memory.access_count
   596→   596→        )
   597→   597→        
   598→   598→        # 4. Importance weight (if stored)
   599→   599→        scores['importance'] = memory.importance or 0.5
   600→   600→        
   601→   601→        # 5. Context relevance
   602→   602→        scores['context'] = self._context_relevance(
   603→   603→            memory, context
   604→   604→        )
   605→   605→        
   606→   606→        # Weighted combination
   607→   607→        weights = {
   608→   608→            'semantic': 0.35,
   609→   609→            'recency': 0.20,
   610→   610→            'frequency': 0.15,
   611→   611→            'importance': 0.15,
   612→   612→            'context': 0.15
   613→   613→        }
   614→   614→        
   615→   615→        return sum(
   616→   616→            scores[k] * weights[k] 
   617→   617→            for k in weights
   618→   618→        )
   619→   619→```

  1075→  1075→        return {
  1076→  1076→            "success": True,
  1077→  1077→            "memory_id": entry_id,
  1078→  1078→            "message": f"Stored in archival memory"
  1079→  1079→        }
  1080→  1080→    
  1081→  1081→    async def archival_memory_search(
  1082→  1082→        self,
  1083→  1083→        query: str,
  1084→  1084→        limit: int = 10
  1085→  1085→    ) -> Dict[str, Any]:
  1086→  1086→        """
  1087→  1087→        Search archival memory semantically.
  1088→  1088→        """
  1089→  1089→        results = []
  1090→  1090→        
  1091→  1091→        if self.vector_db:
  1092→  1092→            # Use vector search
  1093→  1093→            query_embedding = await self._create_embedding(query)
  1094→  1094→            results = await self.vector_db.search(query_embedding, limit)
  1095→  1095→        else:
  1096→  1096→            # Fallback to simple text search
  1097→  1097→            query_lower = query.lower()
  1098→  1098→            for entry in self.archival_memory:
  1099→  1099→                if query_lower in entry.content.lower():
  1100→  1100→                    entry.access_count += 1
  1101→  1101→                    results.append({
  1102→  1102→                        "id": entry.id,
  1103→  1103→                        "content": entry.content,
  1104→  1104→                        "metadata": entry.metadata,
  1105→  1105→                        "score": 1.0  # Simple match
  1106→  1106→                    })
  1107→  1107→        
  1108→  1108→        return {
  1109→  1109→            "success": True,
  1110→  1110→            "results": results[:limit],
  1111→  1111→            "total": len(results)
  1112→  1112→        }

  1119→  1119→        self,
  1120→  1120→        include_working: bool = True,
  1121→  1121→        include_recent_messages: int = 10
  1122→  1122→    ) -> str:
  1123→  1123→        """
  1124→  1124→        Build the context string for the LLM.
  1125→  1125→        Includes core memory and optionally working memory.
  1126→  1126→        """
  1127→  1127→        context_parts = []
  1128→  1128→        
  1129→  1129→        # Core memory (always included)
  1130→  1130→        context_parts.append("=== CORE MEMORY ===")
  1131→  1131→        for label, block in self.core_memory.items():
  1132→  1132→            if block.content:
  1133→  1133→                context_parts.append(f"\n[{label.upper()}]\n{block.content}")
  1134→  1134→        
  1135→  1135→        # Working memory (recent messages)
  1136→  1136→        if include_working and self.working_memory:
  1137→  1137→            context_parts.append("\n=== RECENT MESSAGES ===")
  1138→  1138→            recent = self.working_memory[-include_recent_messages:]
  1139→  1139→            for msg in recent:
  1140→  1140→                role = msg.get("role", "unknown")
  1141→  1141→                content = msg.get("content", "")
  1142→  1142→                context_parts.append(f"\n{role}: {content}")
  1143→  1143→        
  1144→  1144→        return "\n".join(context_parts)

  1174→  1174→```python
  1175→  1175→# Agent loop with self-directed memory
  1176→  1176→class LettaStyleAgent:
  1177→  1177→    """
  1178→  1178→    Agent with self-directed memory management.
  1179→  1179→    """
  1180→  1180→    
  1181→  1181→    def __init__(
  1182→  1182→        self,
  1183→  1183→        llm_client: Any,
  1184→  1184→        memory: SelfDirectedMemory
  1185→  1185→    ):
  1186→  1186→        self.llm = llm_client
  1187→  1187→        self.memory = memory
  1188→  1188→        self.system_prompt = self._build_system_prompt()
  1189→  1189→    
  1190→  1190→    def _build_system_prompt(self) -> str:
  1191→  1191→        """Build system prompt with memory instructions"""
  1192→  1192→        return """
  1193→  1193→You are an AI assistant with self-directed memory capabilities.
  1194→  1194→
  1195→  1195→## Memory Tools Available
  1196→  1196→
  1197→  1197→You have access to the following memory tools:
  1198→  1198→
  1199→  1199→1. **core_memory_append(label, content)**: Add information to core memory
  1200→  1200→   - Use for: User preferences, important facts, ongoing context
  1201→  1201→   - Labels: "persona", "human", "tasks"
  1202→  1202→
  1203→  1203→2. **core_memory_replace(label, old_content, new_content)**: Update existing memory
  1204→  1204→   - Use for: Correcting or updating information
  1205→  1205→
  1206→  1206→3. **archival_memory_insert(content)**: Store for long-term
  1207→  1207→   - Use for: Important information that may be needed later
  1208→  1208→
  1209→  1209→4. **archival_memory_search(query)**: Search long-term memory
  1210→  1210→   - Use for: Recalling past information
  1211→  1211→
  1212→  1212→## Memory Guidelines
  1213→  1213→
  1214→  1214→- Be proactive about remembering important information
  1215→  1215→- Store user preferences and personal details
  1216→  1216→- Update memories when you learn new information
  1217→  1217→- Search your memory before making assumptions
  1218→  1218→- Don't over-store trivial information
  1219→  1219→"""
  1220→  1220→    
  1221→  1221→    async def process_message(
  1222→  1222→        self,
  1223→  1223→        user_message: str
  1224→  1224→    ) -> str:
  1225→  1225→        """Process user message with memory operations"""
  1226→  1226→        
  1227→  1227→        # Add to working memory
  1228→  1228→        self.memory.working_memory.append({
  1229→  1229→            "role": "user",
  1230→  1230→            "content": user_message,
  1231→  1231→            "timestamp": datetime.utcnow().isoformat()
  1232→  1232→        })
  1233→  1233→        
  1234→  1234→        # Build messages for LLM
  1235→  1235→        messages = [
  1236→  1236→            {"role": "system", "content": self.system_prompt},
  1237→  1237→            {"role": "system", "content": self.memory.build_context()},
  1238→  1238→            {"role": "user", "content": user_message}
  1239→  1239→        ]
  1240→  1240→        
  1241→  1241→        # Get LLM response with tool calling
  1242→  1242→        response = await self.llm.chat.completions.create(
  1243→  1243→            model="gpt-4",
  1244→  1244→            messages=messages,
  1245→  1245→            tools=self.memory.tools,
  1246→  1246→            tool_choice="auto"
  1247→  1247→        )
  1248→  1248→        
  1249→  1249→        # Process tool calls
  1250→  1250→        while response.choices[0].message.tool_calls:
  1251→  1251→            tool_calls = response.choices[0].message.tool_calls
  1252→  1252→            
  1253→  1253→            for tool_call in tool_calls:
  1254→  1254→                # Execute the memory tool
  1255→  1255→                result = await self._execute_tool(
  1256→  1256→                    tool_call.function.name,
  1257→  1257→                    json.loads(tool_call.function.arguments)
  1258→  1258→                )
  1259→  1259→                
  1260→  1260→                # Add tool result to messages
  1261→  1261→                messages.append(response.choices[0].message)
  1262→  1262→                messages.append({
  1263→  1263→                    "role": "tool",
  1264→  1264→                    "tool_call_id": tool_call.id,
  1265→  1265→                    "content": json.dumps(result)
  1266→  1266→                })
  1267→  1267→            
  1268→  1268→            # Get next response
  1269→  1269→            response = await self.llm.chat.completions.create(
  1270→  1270→                model="gpt-4",
  1271→  1271→                messages=messages,
  1272→  1272→                tools=self.memory.tools
  1273→  1273→            )
  1274→  1274→        
  1275→  1275→        # Extract final response
  1276→  1276→        final_response = response.choices[0].message.content
  1277→  1277→        
  1278→  1278→        # Add to working memory
  1279→  1279→        self.memory.working_memory.append({
  1280→  1280→            "role": "assistant",
  1281→  1281→            "content": final_response,
  1282→  1282→            "timestamp": datetime.utcnow().isoformat()
  1283→  1283→        })
  1284→  1284→        
  1285→  1285→        return final_response
  1286→  1286→    
  1287→  1287→    async def _execute_tool(
  1288→  1288→        self,
  1289→  1289→        tool_name: str,
  1290→  1290→        arguments: Dict
  1291→  1291→    ) -> Dict:
  1292→  1292→        """Execute a memory tool"""
  1293→  1293→        
  1294→  1294→        if tool_name == "core_memory_append":
  1295→  1295→            return self.memory.core_memory_append(
  1296→  1296→                arguments["label"],
  1297→  1297→                arguments["content"]
  1298→  1298→            )
  1299→  1299→        
  1300→  1300→        elif tool_name == "core_memory_replace":
  1301→  1301→            return self.memory.core_memory_replace(
  1302→  1302→                arguments["label"],
  1303→  1303→                arguments["old_content"],
  1304→  1304→                arguments["new_content"]
  1305→  1305→            )
  1306→  1306→        
  1307→  1307→        elif tool_name == "archival_memory_insert":
  1308→  1308→            return await self.memory.archival_memory_insert(
  1309→  1309→                arguments["content"]
  1310→  1310→            )
  1311→  1311→        
  1312→  1312→        elif tool_name == "archival_memory_search":
  1313→  1313→            return await self.memory.archival_memory_search(
  1314→  1314→                arguments["query"],
  1315→  1315→                arguments.get("limit", 10)
  1316→  1316→            )
  1317→  1317→        
  1318→  1318→        else:
  1319→  1319→            return {"success": False, "error": f"Unknown tool: {tool_name}"}
