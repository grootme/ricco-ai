     1→# Letta (MemGPT) Self-Directed Memory Management Research
     2→
     3→## Executive Summary
     4→
     5→Letta (formerly MemGPT) is a revolutionary platform for building stateful AI agents with self-directed memory management. It implements an OS-inspired hierarchical memory architecture that enables agents to overcome LLM context window limitations through autonomous memory decisions.
     6→
     7→**Key Innovation**: Agents can self-edit their own memory using function tools, deciding what to remember, forget, and consolidate without human intervention.
     8→
     9→---
    10→
    11→## 1. Letta Architecture: Self-Directed Memory Implementation
    12→
    13→### 1.1 Core Concept: LLM as Operating System
    14→
    15→Letta implements the "LLM as Operating System" paradigm from the MemGPT paper (arXiv:2310.08560):
    16→
    17→```
    18→┌─────────────────────────────────────────────────────────────┐
    19→│                    LETTA AGENT ARCHITECTURE                  │
    20→├─────────────────────────────────────────────────────────────┤
    21→│                                                              │
    22→│  ┌─────────────────────────────────────────────────────┐    │
    23→│  │              MAIN CONTEXT (Limited)                  │    │
    24→│  │  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐    │    │
    25→│  │  │   SYSTEM    │ │   CORE      │ │  WORKING    │    │    │
    26→│  │  │   PROMPT    │ │   MEMORY    │ │  MEMORY     │    │    │
    27→│  │  │  (Persona)  │ │  (Blocks)   │ │ (Messages)  │    │    │
    28→│  │  └─────────────┘ └─────────────┘ └─────────────┘    │    │
    29→│  │         ↑ Always in context (like RAM)              │    │
    30→│  └─────────────────────────────────────────────────────┘    │
    31→│                         ↕                                    │
    32→│  ┌─────────────────────────────────────────────────────┐    │
    33→│  │           EXTERNAL MEMORY (Unlimited)                │    │
    34→│  │  ┌─────────────────┐ ┌─────────────────────────┐    │    │
    35→│  │  │     RECALL      │ │      ARCHIVAL           │    │    │
    36→│  │  │     MEMORY      │ │      MEMORY             │    │    │
    37→│  │  │ (Message DB)    │ │ (Vector Database)       │    │    │
    38→│  │  └─────────────────┘ └─────────────────────────┘    │    │
    39→│  │         ↑ Requires retrieval (like Disk)            │    │
    40→│  └─────────────────────────────────────────────────────┘    │
    41→│                                                              │
    42→└─────────────────────────────────────────────────────────────┘
    43→```
    44→
    45→### 1.2 Memory Hierarchy (OS-Inspired)
    46→
    47→| Memory Tier | Analogy | Characteristics | Capacity |
    48→|-------------|---------|-----------------|----------|
    49→| **Main Context** | CPU Registers | Always visible to LLM | Fixed (context window) |
    50→| **Core Memory** | RAM | In-context, self-editable | Limited (~2000-8000 tokens) |
    51→| **Recall Memory** | Page Cache | Conversation history | Semi-limited |
    52→| **Archival Memory** | Disk/SSD | Vector DB, searchable | Unlimited |
    53→

    98→## 2. Memory Tiers: Detailed Breakdown
    99→
   100→### 2.1 Core Memory (Memory Blocks)
   101→
   102→**Definition**: Structured sections of the agent's context window that persist across all interactions. Always visible - no retrieval needed.
   103→
   104→```python
   105→# Core Memory Structure
   106→class CoreMemoryBlock:
   107→    """A structured memory block in core memory"""
   108→    label: str           # e.g., "persona", "human", "tasks"
   109→    content: str         # The actual content
   110→    limit: int           # Character/token limit
   111→    priority: int        # Importance for context management
   112→
   113→# Default Core Memory Blocks
   114→DEFAULT_BLOCKS = {
   115→    "persona": {
   116→        "description": "AI's identity and capabilities",
   117→        "limit": 2000,
   118→        "content": "I am a helpful AI assistant..."
   119→    },
   120→    "human": {
   121→        "description": "User information and preferences",
   122→        "limit": 2000,
   123→        "content": "User prefers Python..."
   124→    }
   125→}
   126→```
   127→
   128→**Key Characteristics**:
   129→- **Always in context**: No retrieval overhead
   130→- **Self-editable**: Agent can modify using tools
   131→- **Structured**: Organized by topic/purpose
   132→- **Limited**: Must be carefully managed
   133→
   134→### 2.2 Working Memory (Message Queue)
   135→
   136→**Definition**: Recent conversation messages in the main context. Analogous to CPU cache.
   137→
   138→```python
   139→# Working Memory Management
   140→class WorkingMemory:
   141→    """Recent messages in main context"""
   142→    
   143→    def __init__(self, max_messages: int = 10):
   144→        self.messages = []
   145→        self.max_messages = max_messages
   146→    
   147→    def add_message(self, message: Message):
   148→        """Add message, evict oldest if needed"""
   149→        self.messages.append(message)
   150→        if len(self.messages) > self.max_messages:
   151→            # Oldest messages moved to recall memory
   152→            self._evict_oldest()
   153→    
   154→    def get_context(self) -> str:
   155→        """Format for LLM context"""
   156→        return "\n".join(m.content for m in self.messages)
   157→```

   360→## 4. Self-Modification: How Agents Modify Their Own Memory
   361→
   362→### 4.1 The Self-Editing Loop
   363→
   364→```
   365→┌─────────────────────────────────────────────────────────────┐
   366→│              SELF-DIRECTED MEMORY MODIFICATION               │
   367→├─────────────────────────────────────────────────────────────┤
   368→│                                                              │
   369→│  User Message                                                │
   370→│       ↓                                                      │
   371→│  ┌─────────────┐                                            │
   372→│  │  LLM sees   │  → Context = System + Core Memory +        │
   373→│  │  context    │    Working Memory + Message                │
   374→│  └─────────────┘                                            │
   375→│       ↓                                                      │
   376→│  ┌─────────────────────────────────────────────────┐        │
   377→│  │  LLM decides:                                     │        │
   378→│  │                                                   │        │
   379→│  │  1. Do I need to REMEMBER this?                  │        │
   380→│  │     → core_memory_append()                       │        │
   381→│  │                                                   │        │
   382→│  │  2. Is this important for long-term?             │        │
   383→│  │     → archival_memory_insert()                   │        │
   384→│  │                                                   │        │
   385→│  │  3. Do I need to UPDATE existing memory?         │        │
   386→│  │     → core_memory_replace()                      │        │
   387→│  │                                                   │        │
   388→│  │  4. Do I need to RECALL past info?               │        │
   389→│  │     → archival_memory_search()                   │        │
   390→│  │     → conversation_search()                      │        │
   391→│  │                                                   │        │
   392→│  │  5. Is this outdated/WRONG?                      │        │
   393→│  │     → archival_memory_delete()                   │        │
   394→│  │                                                   │        │
   395→│  └─────────────────────────────────────────────────┘        │
   396→│       ↓                                                      │
   397→│  Tool Execution → Memory State Updated                       │
   398→│       ↓                                                      │
   399→│  Response Generation                                         │
   400→│                                                              │
   401→└─────────────────────────────────────────────────────────────┘
   402→```

   483→## 5. Key Algorithms: Memory Management
   484→
   485→### 5.1 Context Window Management (Heartbeats)
   486→
   487→Letta uses a "heartbeat" mechanism for context management:
   488→
   489→```python
   490→# Heartbeat-based context management
   491→class HeartbeatManager:
   492→    """
   493→    Periodically triggers context evaluation and management.
   494→    Similar to OS memory management interrupts.
   495→    """
   496→    
   497→    def __init__(self, max_context_tokens: int = 8000):
   498→        self.max_tokens = max_context_tokens
   499→        self.heartbeat_interval = 10  # messages
   500→    
   501→    async def check_and_compact(self, state: AgentState):
   502→        """Check if context compaction is needed"""
   503→        current_tokens = self._count_tokens(state)
   504→        
   505→        if current_tokens > self.max_tokens * 0.8:
   506→            # Trigger compaction
   507→            await self._compact_context(state)
   508→    
   509→    async def _compact_context(self, state: AgentState):
   510→        """Compact context by summarizing old messages"""
   511→        # 1. Summarize old messages
   512→        summary = await self._summarize_messages(
   513→            state.messages[:-5]  # Keep recent 5
   514→        )
   515→        
   516→        # 2. Store summary in archival memory
   517→        await state.archival_memory.insert(
   518→            f"Conversation summary: {summary}"
   519→        )
   520→        
   521→        # 3. Remove compacted messages from working memory
   522→        state.messages = state.messages[-5:]
   523→        
   524→        # 4. Update core memory if needed
   525→        # Agent decides via tool calls
   526→```
   527→
   528→### 5.2 Memory Consolidation
   529→
   530→```python
   531→# Memory consolidation algorithm (conceptual)
   532→class MemoryConsolidation:
   533→    """
   534→    Consolidate information across memory tiers.
   535→    Inspired by sleep-dependent memory consolidation.
   536→    """
   537→    
   538→    async def consolidate_session(self, session_id: str):
   539→        """Consolidate session memories into long-term storage"""
   540→        
   541→        # 1. Extract key facts from session
   542→        session_memories = await self.recall_memory.get_session(session_id)
   543→        key_facts = await self._extract_facts(session_memories)
   544→        
   545→        # 2. Check for conflicts with existing memories
   546→        for fact in key_facts:
   547→            conflicts = await self._find_conflicts(fact)
   548→            
   549→            if conflicts:
   550→                # Resolve conflicts - keep most recent/relevant
   551→                await self._resolve_conflict(fact, conflicts)
   552→            else:
   553→                # Store new fact
   554→                await self.archival_memory.insert(fact)
   555→        
   556→        # 3. Update core memory if user preferences changed
   557→        await self._update_core_memory_preferences()
   558→```

   560→### 5.3 Relevance Scoring
   561→
   562→```python
   563→# Relevance scoring for memory retrieval
   564→class RelevanceScorer:
   565→    """
   566→    Score memory relevance for retrieval decisions.
   567→    """
   568→    
   569→    def compute_relevance(
   570→        self,
   571→        query: str,
   572→        memory: MemoryItem,
   573→        context: Dict
   574→    ) -> float:
   575→        """
   576→        Compute relevance score combining multiple factors.
   577→        
   578→        Returns:
   579→            Score between 0 and 1
   580→        """
   581→        scores = {}
   582→        
   583→        # 1. Semantic similarity (vector embedding)
   584→        scores['semantic'] = self._semantic_similarity(
   585→            query, memory.content
   586→        )
   587→        
   588→        # 2. Recency factor
   589→        scores['recency'] = self._recency_score(
   590→            memory.timestamp
   591→        )
   592→        
   593→        # 3. Access frequency
   594→        scores['frequency'] = self._frequency_score(
   595→            memory.access_count
   596→        )
   597→        
   598→        # 4. Importance weight (if stored)
   599→        scores['importance'] = memory.importance or 0.5
   600→        
   601→        # 5. Context relevance
   602→        scores['context'] = self._context_relevance(
   603→            memory, context
   604→        )
   605→        
   606→        # Weighted combination
   607→        weights = {
   608→            'semantic': 0.35,
   609→            'recency': 0.20,
   610→            'frequency': 0.15,
   611→            'importance': 0.15,
   612→            'context': 0.15
   613→        }
   614→        
   615→        return sum(
   616→            scores[k] * weights[k] 
   617→            for k in weights
   618→        )
   619→```

   708→
   709→```python
   710→# Tool calling flow for memory operations
   711→async def process_message(
   712→    agent: LettaAgent,
   713→    user_message: str
   714→) -> str:
   715→    """Process user message with memory tool calls"""
   716→    
   717→    # 1. Build context
   718→    context = build_context(
   719→        system_prompt=agent.system_prompt,
   720→        core_memory=agent.core_memory,
   721→        working_memory=agent.working_memory,
   722→        message=user_message
   723→    )
   724→    
   725→    # 2. LLM generates response (possibly with tool calls)
   726→    response = await llm.generate(
   727→        messages=context,
   728→        tools=agent.memory_tools,
   729→        tool_choice="auto"  # LLM decides when to use tools
   730→    )
   731→    
   732→    # 3. Process tool calls if any
   733→    while response.tool_calls:
   734→        for tool_call in response.tool_calls:
   735→            # Execute memory tool
   736→            result = await execute_tool(
   737→                tool_call.name,
   738→                tool_call.arguments
   739→            )
   740→            
   741→            # Add result to context
   742→            context.append({
   743→                "role": "tool",
   744→                "name": tool_call.name,
   745→                "content": result
   746→            })
   747→        
   748→        # Get next response
   749→        response = await llm.generate(
   750→            messages=context,
   751→            tools=agent.memory_tools
   752→        )
   753→    
   754→    # 4. Return final response
   755→    return response.content
   756→```

   812→### 7.1 Architecture for Implementation
   813→
   814→```python
   815→# Self-Directed Memory System Implementation
   816→from typing import Dict, List, Optional, Any
   817→from dataclasses import dataclass, field
   818→from datetime import datetime
   819→from enum import Enum
   820→import json
   821→
   822→class MemoryTier(Enum):
   823→    """Memory tier classification"""
   824→    CORE = "core"           # Always in context
   825→    WORKING = "working"     # Recent messages
   826→    RECALL = "recall"       # Conversation history
   827→    ARCHIVAL = "archival"   # Long-term semantic storage
   828→
   829→
   830→@dataclass
   831→class MemoryBlock:
   832→    """A structured memory block"""
   833→    label: str
   834→    content: str
   835→    limit: int = 2000
   836→    priority: int = 1
   837→    created_at: datetime = field(default_factory=datetime.utcnow)
   838→    updated_at: datetime = field(default_factory=datetime.utcnow)
   839→    
   840→    def can_append(self, text: str) -> bool:
   841→        return len(self.content) + len(text) <= self.limit
   842→    
   843→    def append(self, text: str) -> bool:
   844→        if self.can_append(text):
   845→            self.content += text
   846→            self.updated_at = datetime.utcnow()
   847→            return True
   848→        return False
   849→    
   850→    def replace(self, old: str, new: str) -> bool:
   851→        if old in self.content:
   852→            self.content = self.content.replace(old, new)
   853→            self.updated_at = datetime.utcnow()
   854→            return True
   855→        return False
   856→
   857→
   858→@dataclass
   859→class ArchivalEntry:
   860→    """Entry in archival memory"""
   861→    id: str
   862→    content: str
   863→    embedding: Optional[List[float]] = None
   864→    metadata: Dict[str, Any] = field(default_factory=dict)
   865→    created_at: datetime = field(default_factory=datetime.utcnow)
   866→    access_count: int = 0
   867→
   868→
   869→class SelfDirectedMemory:
   870→    """
   871→    Implementation of Letta-style self-directed memory.
   872→    Agents can modify their own memory using tools.
   873→    """
   874→    
   875→    def __init__(
   876→        self,
   877→        agent_id: str,
   878→        vector_db: Optional[Any] = None
   879→    ):
   880→        self.agent_id = agent_id
   881→        
   882→        # Memory Tiers
   883→        self.core_memory: Dict[str, MemoryBlock] = {}
   884→        self.working_memory: List[Dict] = []
   885→        self.recall_memory: List[Dict] = []
   886→        self.archival_memory: List[ArchivalEntry] = []
   887→        
   888→        # Vector database for semantic search
   889→        self.vector_db = vector_db
   890→        
   891→        # Initialize default core memory blocks
   892→        self._init_core_memory()
   893→        
   894→        # Memory tools the agent can call
   895→        self.tools = self._define_tools()
   896→    
   897→    def _init_core_memory(self):
   898→        """Initialize default core memory blocks"""
   899→        self.core_memory = {
   900→            "persona": MemoryBlock(
   901→                label="persona",
   902→                content="I am a helpful AI assistant with persistent memory.",
   903→                limit=2000
   904→            ),
   905→            "human": MemoryBlock(
   906→                label="human", 
   907→                content="",
   908→                limit=2000
   909→            ),
   910→            "tasks": MemoryBlock(
   911→                label="tasks",
   912→                content="",
   913→                limit=1000
   914→            )
   915→        }
   916→    
   917→    def _define_tools(self) -> List[Dict]:
   918→        """Define memory tools the agent can use"""
   919→        return [
   920→            {
   921→                "name": "core_memory_append",
   922→                "description": "Append content to a core memory block",
   923→                "parameters": {
   924→                    "type": "object",
   925→                    "properties": {
   926→                        "label": {
   927→                            "type": "string",
   928→                            "enum": list(self.core_memory.keys())
   929→                        },
   930→                        "content": {"type": "string"}
   931→                    },
   932→                    "required": ["label", "content"]
   933→                }
   934→            },
   935→            {
   936→                "name": "core_memory_replace",
   937→                "description": "Replace content in a core memory block",
   938→                "parameters": {
   939→                    "type": "object",
   940→                    "properties": {
   941→                        "label": {"type": "string"},
   942→                        "old_content": {"type": "string"},
   943→                        "new_content": {"type": "string"}
   944→                    },
   945→                    "required": ["label", "old_content", "new_content"]
   946→                }
   947→            },

   949→                "name": "archival_memory_insert",
   950→                "description": "Store information in long-term memory",
   951→                "parameters": {
   952→                    "type": "object",
   953→                    "properties": {
   954→                        "content": {"type": "string"}
   955→                    },
   956→                    "required": ["content"]
   957→                }
   958→            },
   959→            {
   960→                "name": "archival_memory_search",
   961→                "description": "Search long-term memory semantically",
   962→                "parameters": {
   963→                    "type": "object",
   964→                    "properties": {
   965→                        "query": {"type": "string"},
   966→                        "limit": {"type": "integer", "default": 10}
   967→                    },
   968→                    "required": ["query"]
   969→                }
   970→            },
   971→            {
   972→                "name": "conversation_search",
   973→                "description": "Search past conversations",
   974→                "parameters": {
   975→                    "type": "object",
   976→                    "properties": {
   977→                        "query": {"type": "string"},
   978→                        "limit": {"type": "integer", "default": 10}
   979→                    },
   980→                    "required": ["query"]
   981→                }
   982→            }
   983→        ]
   984→    
   985→    # ==========================================
   986→    # Core Memory Operations
   987→    # ==========================================
   988→    
   989→    def core_memory_append(
   990→        self,
   991→        label: str,
   992→        content: str
   993→    ) -> Dict[str, Any]:
   994→        """
   995→        Append content to a core memory block.
   996→        Called by the agent through tool use.
   997→        """
   998→        if label not in self.core_memory:
   999→            return {
  1000→                "success": False,
  1001→                "error": f"Unknown memory block: {label}"
  1002→            }
  1003→        
  1004→        block = self.core_memory[label]
  1005→        
  1006→        if block.append(content):
  1007→            return {
  1008→                "success": True,
  1009→                "message": f"Appended to {label}. Block size: {len(block.content)}/{block.limit}",
  1010→                "block_size": len(block.content)
  1011→            }
  1012→        else:
  1013→            return {
  1014→                "success": False,
  1015→                "error": f"Block {label} is full. Current: {len(block.content)}/{block.limit}"
  1016→            }
  1017→    
  1018→    def core_memory_replace(
  1019→        self,
  1020→        label: str,
  1021→        old_content: str,
  1022→        new_content: str
  1023→    ) -> Dict[str, Any]:
  1024→        """
  1025→        Replace content in a core memory block.
  1026→        Called by the agent through tool use.
  1027→        """
  1028→        if label not in self.core_memory:
  1029→            return {
  1030→                "success": False,
  1031→                "error": f"Unknown memory block: {label}"
  1032→            }
  1033→        
  1034→        block = self.core_memory[label]
  1035→        
  1036→        if block.replace(old_content, new_content):
  1037→            return {
  1038→                "success": True,
  1039→                "message": f"Updated {label}"
  1040→            }
  1041→        else:
  1042→            return {
  1043→                "success": False,
  1044→                "error": f"Content not found in {label}"
  1045→            }
  1046→    
  1047→    # ==========================================
  1048→    # Archival Memory Operations
  1049→    # ==========================================
  1050→    
  1051→    async def archival_memory_insert(
  1052→        self,
  1053→        content: str,
  1054→        metadata: Optional[Dict] = None
  1055→    ) -> Dict[str, Any]:
  1056→        """
  1057→        Store information in archival memory.
  1058→        Creates embedding for semantic search.
  1059→        """
  1060→        entry_id = f"arch_{len(self.archival_memory)}"
  1061→        
  1062→        entry = ArchivalEntry(
  1063→            id=entry_id,
  1064→            content=content,
  1065→            metadata=metadata or {}
  1066→        )
  1067→        
  1068→        # Create embedding if vector DB available
  1069→        if self.vector_db:
  1070→            entry.embedding = await self._create_embedding(content)
  1071→            await self.vector_db.insert(entry)
  1072→        
  1073→        self.archival_memory.append(entry)
  1074→        
  1075→        return {
  1076→            "success": True,
  1077→            "memory_id": entry_id,
  1078→            "message": f"Stored in archival memory"
  1079→        }
  1080→    
  1081→    async def archival_memory_search(
  1082→        self,
  1083→        query: str,
  1084→        limit: int = 10
  1085→    ) -> Dict[str, Any]:
  1086→        """
  1087→        Search archival memory semantically.
  1088→        """
  1089→        results = []
  1090→        
  1091→        if self.vector_db:
  1092→            # Use vector search
  1093→            query_embedding = await self._create_embedding(query)
  1094→            results = await self.vector_db.search(query_embedding, limit)
  1095→        else:
  1096→            # Fallback to simple text search
  1097→            query_lower = query.lower()
  1098→            for entry in self.archival_memory:
  1099→                if query_lower in entry.content.lower():
  1100→                    entry.access_count += 1
  1101→                    results.append({
  1102→                        "id": entry.id,
  1103→                        "content": entry.content,
  1104→                        "metadata": entry.metadata,
  1105→                        "score": 1.0  # Simple match
  1106→                    })
  1107→        
  1108→        return {
  1109→            "success": True,
  1110→            "results": results[:limit],
  1111→            "total": len(results)
  1112→        }
  1113→    
  1114→    # ==========================================
  1115→    # Context Building
  1116→    # ==========================================
  1117→    
  1118→    def build_context(
  1119→        self,
  1120→        include_working: bool = True,
  1121→        include_recent_messages: int = 10
  1122→    ) -> str:
  1123→        """
  1124→        Build the context string for the LLM.
  1125→        Includes core memory and optionally working memory.
  1126→        """
  1127→        context_parts = []
  1128→        
  1129→        # Core memory (always included)
  1130→        context_parts.append("=== CORE MEMORY ===")
  1131→        for label, block in self.core_memory.items():
  1132→            if block.content:
  1133→                context_parts.append(f"\n[{label.upper()}]\n{block.content}")
  1134→        
  1135→        # Working memory (recent messages)
  1136→        if include_working and self.working_memory:
  1137→            context_parts.append("\n=== RECENT MESSAGES ===")
  1138→            recent = self.working_memory[-include_recent_messages:]
  1139→            for msg in recent:
  1140→                role = msg.get("role", "unknown")
  1141→                content = msg.get("content", "")
  1142→                context_parts.append(f"\n{role}: {content}")
  1143→        
  1144→        return "\n".join(context_parts)
  1145→    
  1146→    # ==========================================
  1147→    # Helper Methods
  1148→    # ==========================================
  1149→

  1151→        """Create embedding for text (placeholder)"""
  1152→        # In production, use actual embedding model
  1153→        # return await embedding_model.embed(text)
  1154→        return []
  1155→    
  1156→    def get_memory_state(self) -> Dict[str, Any]:
  1157→        """Get current memory state for system prompt"""
  1158→        return {
  1159→            "core_memory": {
  1160→                label: {
  1161→                    "content": block.content,
  1162→                    "size": len(block.content),
  1163→                    "limit": block.limit
  1164→                }
  1165→                for label, block in self.core_memory.items()

  1167→            "working_memory_count": len(self.working_memory),
  1168→            "archival_count": len(self.archival_memory)
  1169→        }

  1177→    """

  1221→    async def process_message(
  1222→        self,

  1224→    ) -> str:
  1225→        """Process user message with memory operations"""
  1226→

  1228→        self.memory.working_memory.append({
  1229→            "role": "user",
  1230→            "content": user_message,
  1231→            "timestamp": datetime.utcnow().isoformat()
  1232→        })
  1233→        
  1234→        # Build messages for LLM
  1235→        messages = [
  1236→            {"role": "system", "content": self.system_prompt},

  1238→            {"role": "user", "content": user_message}
  1239→        ]
  1240→        
  1241→        # Get LLM response with tool calling
  1242→        response = await self.llm.chat.completions.create(

  1250→        while response.choices[0].message.tool_calls:
  1251→            tool_calls = response.choices[0].message.tool_calls
  1252→            
  1253→            for tool_call in tool_calls:
  1254→                # Execute the memory tool
  1255→                result = await self._execute_tool(
  1256→                    tool_call.function.name,
  1257→                    json.loads(tool_call.function.arguments)
  1258→                )
  1259→                
  1260→                # Add tool result to messages
  1261→                messages.append(response.choices[0].message)
  1262→                messages.append({
  1263→                    "role": "tool",
  1264→                    "tool_call_id": tool_call.id,
  1265→                    "content": json.dumps(result)
  1266→                })
  1267→            
  1268→            # Get next response
  1269→            response = await self.llm.chat.completions.create(
  1270→                model="gpt-4",
  1271→                messages=messages,
  1272→                tools=self.memory.tools
  1273→            )
  1274→        
  1275→        # Extract final response
  1276→        final_response = response.choices[0].message.content
  1277→        
  1278→        # Add to working memory
  1279→        self.memory.working_memory.append({
  1280→            "role": "assistant",
  1281→            "content": final_response,
  1282→            "timestamp": datetime.utcnow().isoformat()
  1283→        })
  1284→        
  1285→        return final_response
  1286→    
  1287→    async def _execute_tool(
  1288→        self,
  1289→        tool_name: str,
  1290→        arguments: Dict

  1293→        
  1294→        if tool_name == "core_memory_append":
  1295→            return self.memory.core_memory_append(
  1296→                arguments["label"],
  1297→                arguments["content"]
  1298→            )
  1299→        
  1300→        elif tool_name == "core_memory_replace":
  1301→            return self.memory.core_memory_replace(
  1302→                arguments["label"],
  1303→                arguments["old_content"],
  1304→                arguments["new_content"]
  1305→            )
  1306→        
  1307→        elif tool_name == "archival_memory_insert":
  1308→            return await self.memory.archival_memory_insert(
  1309→                arguments["content"]
  1310→            )
  1311→        
  1312→        elif tool_name == "archival_memory_search":
  1313→            return await self.memory.archival_memory_search(
  1314→                arguments["query"],
  1315→                arguments.get("limit", 10)
  1316→            )
  1317→        
  1318→        else:
  1319→            return {"success": False, "error": f"Unknown tool: {tool_name}"}
