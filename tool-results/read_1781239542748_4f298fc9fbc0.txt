   255→<p>The paper “<a href="https://arxiv.org/abs/2310.08560">MemGPT: Towards LLMs as Operating Systems</a>” (2023) by Charles Packer, Sarah Wooders, Kevin Lin, Vivian Fang, Shishir G. Patil, and Joseph E. Gonzalez introduces a <strong>memory management system for LLMs</strong>.</p>
   256→<blockquote class="blockquote">
   257→<p>To enable using context beyond limited context windows, we propose <em>virtual context management</em>, a technique drawing inspiration from hierarchical memory systems […] which provide the illusion of an extended virtual memory via paging between physical memory and disk. Using this technique, we introduce <strong>MemGPT (MemoryGPT), a system that intelligently manages different storage tiers</strong> […].</p>
   258→</blockquote>
   259→<p>This article reviews the <strong>MemGPT paper</strong> and implements a <strong>MemGPT agent</strong> using the <a href="https://www.letta.com/"><strong>Letta framework</strong></a>.</p>
   260→<div class="callout callout-style-default callout-tip callout-titled">
   261→<div class="callout-header d-flex align-content-center">
   262→<div class="callout-icon-container">

   266→Tip
   267→</div>
   268→</div>
   269→<div class="callout-body-container callout-body">
   270→<p><a href="https://www.letta.com/blog/memgpt-and-letta">As of September 2024, MemGPT is part of Letta</a>. While MemGPT refers to the agent design pattern with two tiers of memory introduced in the research paper, Letta is an open-source agent framework that helps developers build <strong>persistent</strong> agents.</p>
   271→</div>

   285→<section id="what-is-memgpt" class="level2">
   286→<h2 class="anchored" data-anchor-id="what-is-memgpt">What is MemGPT</h2>
   287→<p>According to the paper, MemGPT is</p>
   288→<blockquote class="blockquote">
   289→<p>[…] an OS-inspired LLM system that teaches LLMs to manage their own memory to achieve unbounded context.</p>
   290→</blockquote>
   291→<p>MemGPT is motivated by the limitations of transformer-based LLMs’ context windows: One the one hand, the computational time and memory costs of LLMs scale quadratically with the context window. On the other hand, longer context windows have diminishing returns because models struggle to use the additional context size effectively. Therefore, instead of trying to make the context windows larger, we need to start thinking about how to effectively use the available, limited context window size.</p>
   292→<p>MemGPT introduces <strong>virtual context management</strong> inspired by virtual memory paging in operating systems, where information is paged in and out of main memory from disk:</p>
   293→<table class="caption-top table">
   294→<thead>
   295→<tr class="header">
   296→<th>Operating System</th>
   297→<th>LLM OS (MemGPT)</th>
   298→</tr>
   299→</thead>
   300→<tbody>
   301→<tr class="odd">
   302→<td>Main memory/physical memory/RAM</td>
   303→<td>Main context</td>
   304→</tr>
   305→<tr class="even">
   306→<td>Memory/disk storage</td>
   307→<td>External context</td>
   308→</tr>
   309→<tr class="odd">
   310→<td>Virtual memory</td>
   311→<td>Virtual context</td>
   312→</tr>
   313→</tbody>
   314→</table>
   315→<p>That means, a MemGPT agent leverages function calling to manage what goes into their limited context window and what needs to be removed.</p>
   316→<blockquote class="blockquote">
   317→<p>Using function calls, LLM agents can read and write to external data sources, modify their own context, and choose when to return responses to the user.</p>
   318→</blockquote>

   343→<section id="two-tier-memory-design-pattern-of-memgpt" class="level2">
   344→<h2 class="anchored" data-anchor-id="two-tier-memory-design-pattern-of-memgpt">Two tier memory design pattern of MemGPT</h2>
   345→<p>The MemGPT agent design pattern has a two tier memory architecture which differentiates between two primary memory types:</p>
   346→<ul>
   347→<li><strong>Tier 1: Main context</strong> (in-context) contains core memories</li>
   348→<li><strong>Tier 2: External context</strong> (out-of-context) contains recall storage and archival storage</li>
   349→</ul>
   350→<!--![](images/memgpt_memory_tiers.webp)-->
   351→<section id="main-context" class="level3">
   352→<h3 class="anchored" data-anchor-id="main-context">Main context</h3>
   353→<p>The first tier of memories is contained in the main context. You can think of the LLMs context window as the main context.</p>
   354→<blockquote class="blockquote">
   355→<p><strong>Main context</strong> is the standard fixed-context window in modern language models — anything in main context is considered <strong>in-context</strong> and can be accessed by the LLM processor during inference.</p>
   356→</blockquote>
   357→<!-- ![](images/memgpt_context_window.webp)
